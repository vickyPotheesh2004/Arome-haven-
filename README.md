# ☕ Arome Haven  
### Because choosing coffee should be smarter than guessing.

> *“Life is too short for bad coffee.”*

---

## 🌍 About the Project

**Arome Haven** is an AI-inspired coffee recommendation web application that helps users discover beverages based on their personal taste preferences. Instead of scrolling through long menus, users interact with a clean, swipe-style UI that makes choosing coffee fast, fun, and intuitive.

This project is currently a **frontend-focused prototype**, built with scalability in mind for future AI and backend integration.

---

## 🤔 Why Arome Haven?

Coffee menus are confusing:
- Too many options  
- No personalization  
- Beginners don’t know where to start  

**Arome Haven solves this by:**
- Focusing on individual taste
- Simplifying decisions
- Preparing the ground for AI-driven recommendations

Instead of overwhelming users with long menus, the app presents a **clean, swipe-based interface** that helps users discover drinks they’ll actually enjoy.

---

## 🎯 Problem Statement

Coffee menus today suffer from:
- Too many choices with unclear flavor descriptions  
- Zero personalization  
- Repetitive ordering habits  
- Poor UX for first-time coffee drinkers  

**Result:** Users guess instead of choosing confidently.

---

## 💡 Solution

Arome Haven solves this by:
- Capturing user taste preferences  
- Matching them with curated menu items  
- Displaying results in an intuitive, swipe-based UI  
- Preparing the foundation for AI-driven intelligence
