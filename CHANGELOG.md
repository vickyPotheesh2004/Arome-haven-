## [0.1.0] - 2025-01-15

### Added
- Initial release of Arome Haven
- React + TypeScript frontend
- Vite build system
- Framer Motion animations
- Swipe-based card interface
- Shopping cart functionality
- Gemini AI service integration
- Responsive UI components
- Product catalog with categories
- Checkout flow
- Order history page

### Features
- **SwipeDeck**: Interactive card-swiping interface for product discovery
- **CartDrawer**: Slide-out shopping cart with quantity management
- **StoreContext**: Global state management for cart and preferences
- **GeminiService**: AI-powered recommendation engine (planned)
- **Responsive Design**: Mobile-first responsive layout
